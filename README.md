# Pixora - Modern Image Discovery Platform

[cite_start]A Pinterest-inspired image gallery featuring a masonry layout and smooth discovery flow.

## 🚀 Key Features
- [**Dynamic API Fetching**: Integrated **Pexels API** via Axios for high-quality image sourcing.
- **Masonry Layout**: Implemented a responsive grid that adjusts beautifully to different screen sizes.
- **Smooth Animations**: Used **Framer Motion** for elegant hover effects and image loading states.

## 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS.
- **Data Fetching**: Axios / REST APIs.
